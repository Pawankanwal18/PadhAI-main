## 🚀 How to Use

### Step 1: Restart Backend with RAG
```bash

cd "ai projeect/backend"
# Press Ctrl+C in the terminal running the backend

# Start fresh with RAG integration
node server.js
```

You should see:
```
✅ PadhAI Backend running on http://localhost:3001
   🤖 Anthropic Claude: Connected
   📚 RAG System: Ready
```

### Step 2: Test RAG Endpoints
```bash

curl http://localhost:3001/api/rag/report
```

```bash

  -H "Content-Type: application/json" \
```


## 🔍 How RAG Improves Question Quality

### Before RAG:
```
User Query → Anthropic API → Generic Question
```
Issues:
- No format consistency
- Unpredictable difficulty
- May not match exam style
- No topic-specific examples

### With RAG:
```
User Query 
    ↓
Retrieve similar questions from dataset
    ↓
Build context with examples
    ↓
Anthropic API (with context)
    ↓
High-quality question matching dataset style
```

Benefits:
- ✅ Format consistency with past papers
- ✅ Appropriate difficulty level
- ✅ Exam-aligned question structure
- ✅ Topic-specific examples as reference
- ✅ Better student preparation

## ⚙️ Performance Considerations

### Optimization Tips:
1. **Add Topic Filter** - Narrows search space
2. **Adjust topK** - Lower = faster (default: 5)
3. **Use Specific Keywords** - Better matching
4. **Install Embeddings** - Faster semantic search
   ```bash
   pip install sentence-transformers
   ```

### Response Times:
- Health check: ~1ms
- Report generation: ~10ms
- Topic retrieval: ~50ms
- Question generation: ~2-3 seconds (limited by Anthropic API)
