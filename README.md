# 🧠 PadhAI – AI-Based Exam Question Predictor

Welcome to **PadhAI**, an AI-powered exam preparation platform designed to help students prepare smarter.

PadhAI analyzes previously stored question papers and uses AI techniques to predict the most relevant and frequently asked questions for upcoming exams. By leveraging historical exam data and intelligent retrieval methods, it provides students with focused study material and improves exam preparation efficiency.

---

## 🚀 Features

- 📚 AI-powered question prediction
- 🗂️ Historical question paper database
- 🔍 Smart semantic search using embeddings
- 🤖 RAG (Retrieval-Augmented Generation) architecture
- ⚡ Fast and accurate question retrieval
- 📈 Optimized dataset processing
- 🌐 User-friendly web interface

## 🎯 Objective

The goal of this project is to assist students in identifying important exam questions by analyzing historical question papers and applying AI-based retrieval techniques. It helps students focus on high-priority topics, making exam preparation more efficient and data-driven.

## ⚠️ Disclaimer

This project predicts questions based on historical exam patterns and stored datasets. The predicted questions are intended to assist students in their preparation and do **not** guarantee the actual questions that will appear in examinations.
